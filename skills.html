CHENEY的skill清單

Claude Code/claude.ai 目前可用的所有 skill:它是做什麼的、怎麼叫、去哪裡下載。

盤點日期 2026-09-24 · 來源:~/.claude/skills、claude.ai 同步 skill、已安裝外掛、Claude Code 內建

通用使用方式

  • 斜線指令:在 Claude Code 輸入 /skill名稱 參數,例如 /ui-ux-pro-max 幫我做 SaaS 定價頁。
  • 自然語言觸發:直接描述需求(例:「幫我把這份 Excel 清乾淨」),Claude 會依 skill 描述自動載入。
  • 命名空間:外掛/同步來的 skill 會帶前綴,如 /impeccable:impeccable、/anthropic-skills:pptx;沒撞名時可省略前綴。
  • 本機 skill 位置:~/.claude/skills/<名稱>/SKILL.md;專案層級放 .claude/skills/。
  • 外掛管理:/plugin 開啟外掛面板;/plugin marketplace add 擁有者/repo 加來源、/plugin install 名稱@marketplace 安裝。
清單以本機實際安裝為準;要更新時請 Claude「重新盤點 skill 清單並更新 skills.html」。
